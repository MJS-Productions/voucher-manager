# Voucher Manager

Professional management and distribution of unique voucher codes for WordPress.

> Simple for users. Reliable for businesses.

**Status:** Early development  
**Current milestone:** `0.2.0-alpha.1`

## Features in this alpha

- versioned database lifecycle;
- system dashboard;
- pool creation and editing;
- active/inactive pool status;
- safe deletion of empty pools;
- privacy-first data model.
