# Translator Notes

## Product object

Translate `One-Time Code` consistently as the language's approved product object. For German, use `Einmalcode`.

Short action labels may still use `Code` where the workflow is unambiguous:

- Import Codes
- Distribute Code
- Copy Code

## Pool

`Pool` is a product concept: a named collection of One-Time Codes. Do not interpret it as a swimming pool.

## Inventory

`Inventory` means the privacy-safe code stock and lifecycle overview. German target: `Bestand`.

## Distribution

`Distribution` means manually assigning one available One-Time Code. German target: `Ausgabe`.

## Statuses

`Available` and `Assigned` often carry the context `One-Time Code status`.

Persisted values remain `available` and `assigned`; only presentation labels are translated.

## Privacy

`One-Time Code value` means the complete sensitive value. `Reference` means the masked Inventory representation.

## Placeholders

Preserve placeholder type and numbering. Numbered placeholders may be reordered in translation.

## Destructive confirmations

First-person acknowledgement is intentional in destructive consent copy. Neutral-professional language remains the general UI style.
