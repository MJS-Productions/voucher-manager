# Dashboard

The Voucher Manager dashboard is the starting point for routine administration.

## Inventory overview

The primary metrics are:

- available codes;
- distributed codes;
- pools;
- imports.

## Quick actions

The dashboard links directly to:

- Create Pool;
- Import Codes;
- Distribute Code.

## Recent activity

The five most recent operational events are displayed using readable labels and
privacy-safe details. Actual voucher values are never shown in the activity list.
