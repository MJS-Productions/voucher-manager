# ADR 0028: Product Language Contract

## Status

Accepted for Sprint 9 Part 2.

## Decision

Use `One-Time Code` as the defined English user-facing domain object and `Einmalcode` as the German target term.

Keep concise action labels such as `Import Codes`, `Distribute Code` and `Copy Code`.

Use neutral-professional wording and avoid direct second-person address where an impersonal formulation is natural.

Keep the current product name until the separate naming decision.

Do not rename stable technical identifiers as part of language polish.

## Consequences

The English source language becomes a consistent base for `de_DE`. Future UI work has a documented terminology and tone contract.
