# Voucher Manager 1.0.0 — Initial Stable Release

**Professional One-Time Code Management for WordPress**

Voucher Manager 1.0.0 is the first stable release of Voucher Manager Free.

## Highlights

- Pool-based One-Time Code management
- TXT and CSV imports with protected rollback
- Secure atomic distribution and one-use request protection
- Privacy-aware Activity history and configurable retention
- Inventory, lifecycle and uninstall boundaries
- English and German administration experience
- Deterministic translation compilation
- Automated PHP quality, integration and release-artifact validation

## Final polish

- Public WordPress author identity: **MJS-Productions**
- One-Time Code values are not logged in Activity history
- Separate Activity empty states for fresh installations and filters without matches
- Neutral German guidance without direct Du/Sie address

## Upgrade boundary

No database schema migration is introduced. Existing 1.0.0 release-candidate installations can be updated in place.

## Validation

Publication requires the complete quality chain, deterministic translation compilation and release-artifact validation. Official WordPress smoke tests use the artifact produced by GitHub Actions.
