# Voucher Manager 1.0.1 — Distribution Context Update

**Professional One-Time Code Management for WordPress**

Voucher Manager 1.0.1 is a focused maintenance release for the Distribution result experience.

## Changed

- Successful Distribution results now show the source Pool name.
- Remaining inventory is presented as an explicit label.
- Singular and plural wording is handled correctly for one or multiple remaining One-Time Codes.
- German translations now display `Pool: …` and `Verbleibender Bestand: …`.

## Upgrade boundary

No database schema migration is introduced. Existing Voucher Manager 1.0.0 installations can be updated in place.

## Validation

Publication requires the complete quality chain, deterministic translation compilation and release-artifact validation. Official WordPress smoke tests use the artifact produced by GitHub Actions.
